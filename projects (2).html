Automated Attendance System Using Face Recognition

A system that automatically marks student attendance by recognizing faces through a camera, instead of a manual roll call or sign-in sheet. It captures a face, matches it against a stored set of registered student faces, and logs attendance when a match is found — reducing time lost to manual attendance and the chance of proxy attendance.
